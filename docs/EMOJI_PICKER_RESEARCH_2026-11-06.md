# 表情选择器调研（2026-11-06）

## 已有能力与冻结参考

`MdColorPicker` 是独立的颜色选择工作流；仓库没有表情数据与选取控件。检索未发现可直接复用的 Avalonia 表情选择器（不保证生态中绝无类似项目）。仅阅读 [`emoji_picker_flutter` 4.5.4 的固定 README](https://github.com/Fintasys/emoji_picker_flutter/blob/6b74e4e5b7f43560aaac72e84f19c9771fe55841/README.md)、pubspec 与 LICENSE：该快照许可为 **MIT**（Copyright 2024 Stefan Humm），此前候选表的 BSD-2-Clause 判断已修正。未阅读或复制 Dart 源码、表情数据、字体、图像或外观。manifest 与 notices 固定了来源与处置。

## 独立设计

Extra `MdEmojiPicker` 以按钮选择字符串，提供类别、名称/关键词搜索和实例内去重最近使用；中文/英文内置示例名、搜索栏、类别、空态及结果截断提示有本地化。控件内仅人工挑选 16 个示例 Unicode 字符串，并非完整 Unicode/CLDR 数据集。宿主可以注入不可变 `MdEmojiItem` 记录与额外多码点序列，也可以自备字体；呈现能力由系统/宿主字体决定，不捆绑字体或声称跨平台均为彩色。逐项按钮有描述性 automation 名称和键盘操作；每次选择通过事件返回，宿主负责插入文本或复制。

结果数量有限制并显示截断提示，避免一次创建任意多按钮；过滤仍会遍历宿主提供的完整集合，非虚拟化搜索。可观察集合仅在附着期间监听，重新附着时重新读取；所有集合更新应在 UI 线程。最近使用仅在当前控件实例中保存，不跨会话。

## 不纳入

首期不包含完整 emoji 数据库、CLDR 注释或翻译、肤色选择器、自动字体覆盖检测、最近使用持久化、剪贴板或编辑器操作、箭头键网格导航、虚拟化、动画、Flutter API 或像素兼容。宿主可以将所需的肤色变体作为独立项提供，但控件不自动生成或替换变体。
